# 🛡️ Tabiline v1.0.1 — ライセンスと公開情報を整備

## ✨ 1.0.0からの変更

### 📜 第三者ライセンスを整備

- リリース用の依存ライブラリ82件について、間接的に使用するものも含めた一覧を追加しました。
- 配布ライブラリに含まれるライセンス・通知67件を保持し、関連文書をAPKへ同梱しました。
- Apache 2.0と、DataStoreに含まれるProtocol BuffersのBSDライセンスを明示しました。
- ビルド時に一部のライセンス文書を除外していた設定を見直しました。

### 🔒 データの取り扱いを分かりやすく

- READMEに、端末の設定によってAndroidのクラウドバックアップや端末間転送の対象となることを追記しました。
- バックアップ機能そのものの動作変更ではありません。Tabiline独自のクラウド同期を追加するものでもありません。

### 🖼️ READMEと権利表記を更新

- アプリアイコンと、乗り換えを含む実画面の紹介画像をREADMEへ追加しました。掲載旅程は架空のサンプルです。
- GitHub上での閲覧・フォークなど、利用規約で認められる範囲をLICENSEに明記しました。アプリ本体をオープンソース化する変更ではありません。
- 個人の添付画像や秘密鍵などの誤登録を防ぐため、Gitの除外設定を強化しました。

今回の更新はライセンス同梱と説明の整備が中心です。旅行データの形式や、移動を登録・表示する基本機能は変更していません。

## 📢 過去バージョンのサポートについて

本リリースの公開をもって、1.0.0を含む過去のすべてのバージョンのサポートを終了します。1.0.1へのアップデートをお願いします。
