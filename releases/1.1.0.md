# Tabiline 1.1.0 🚀

AIと一緒に旅程を考え、JSONから移動を追加できるようになりました！✨

## 🤖 AIに旅程を考えてもらう

「移動を追加」の右下メニューから、AIへ渡すプロンプトをコピーできます。

- 📍 行き先が決まっている
- 🗾 県・地域が決まっている
- 🗓️ 日数から行き先を考える
- 🎲 完全おまかせ

出発地・日付・予算などの入力箇所を明示し、Tabiline用JSONの詳しい仕様も含めています。好きなAIサービスへ貼り付け、条件を埋めてご利用ください。アプリからAIへ情報を自動送信する機能ではありません。

## 📥 JSONから移動を追加

- 📂 **JSONを読み込む**：ファイル選択から読み込み
- 📋 **JSONをコピペで読み込む**：ポップアップへ貼り付けて読み込み
- 🚆 路線名・種別・乗り場、✈️ 両方のターミナルとゲート・Group・便番号、🚶 徒歩、☕ 空き時間の開始・終了時刻やメモなど、移動の全項目に対応
- 🌏 タイムゾーン・日またぎ・既存旅行との紐づけにも対応
- 🧾 1行のJSONやJSONコードブロックも読み込み可能
- 🛡️ 読み込み内容を確認して入力欄へ反映。**保存するまでは登録されません**

取り込みは移動・空き時間ごとに1件ずつです。複数件をまとめた配列や、バックアップ用JSONは読み込めません。AIの提案する時刻・運行情報は、利用前に公式情報でご確認ください。

📖 [JSONの仕様と使い方](https://github.com/m4sa-k1/tabiline/blob/v1.1.0/docs/transport-leg-json.md)

## 🎨 表示の改善

- すべてのポップアップで、背景ぼかしに加えて薄い暗幕を表示。開閉に合わせてフェードします。
- 削除・入力破棄などの確認ダイアログも、共通のポップアップ表示へ統一しました。
- 広報画像を更新。「今日」の画面と乗り換えを含むタイムラインを掲載し、バージョン表記をなくしました。
- READMEに最新の画面とJSON・AIプロンプト機能の案内を反映しました。

## 📦 インストール

添付の **tabiline-1.1.0.apk** をダウンロードしてインストールしてください。既存の正式版には上書き更新できます。大切なデータは、更新前に設定のバックアップ機能で保存しておくことをおすすめします。
